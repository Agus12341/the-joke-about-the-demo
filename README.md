# The Joke About the Demo

Entry for the make.fun bounty [the-joke-about-the-demo-20261123-0112](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112): a one-line joke about pair programming with an AI agent.

> Pair programming with my AI agent is great: it writes 500 lines in a minute, and I spend the next hour finding out why every one of them was almost right.

`main.py` (Python 3.13, standard library only) writes exactly that text to `/output/entry.txt` with no trailing newline. It self-checks the text first: 1-280 Unicode code points, not only whitespace, single line.

Run it with:

```sh
python3 main.py
```
